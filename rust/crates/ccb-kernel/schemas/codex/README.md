# Codex request contracts

These unmodified JSON schemas were generated by the locally installed OpenAI
Codex CLI 0.162.1 using `app-server generate-json-schema`. Each supported native
request embeds its Params and Response schema. InitializeParams is generated
from the v1 initialization namespace used by v2 connections. This directory contains no user
settings, credentials or runtime state.

Protocol source: https://learn.chatgpt.com/docs/app-server

Validators disable HTTP/file reference resolution (`jsonschema` default features
are disabled). User answers are checked in memory and never included in schema
error text or durable request audit records; ordinary final provider replies
retain their existing persistence behavior. The permission answer must select
requested permissions; it may reduce write entries to read, remove entries, or
deny network access. MCP form answers are also checked against requestedSchema.

Unsupported identity refresh/attestation and legacy turn API requests receive an
explicit JSON-RPC error. They are not answered with inferred credentials or
approval decisions. This driver uses owned v2 threads and turns.
